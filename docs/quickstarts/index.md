## How to Use These Guides

Each quickstart follows the same structure:

| Section | Purpose |
|---------|---------|
| **Persona & Typical Day** | Understand the role and daily responsibilities |
| **Your First 30 Minutes** | Hands-on guided path with 3-5 linked tutorials |
| **Your First Week** | Expanded learning path for deeper proficiency |
| **Key Features Table** | Feature-to-doc mapping with role-specific rationale |
| **Common Pitfalls** | Mistakes to avoid based on real-world patterns |
| **Related Resources** | Grid cards linking to the most relevant docs |
