## 🚀 Quick Start

### Using the Progress Tracker

1. Copy the template from `PROGRESS_TRACKER_TEMPLATE.md`
2. Paste into your tutorial README
3. Update the tutorial numbers and titles
4. Mark your current position as `CURRENT`

### Progress States

| State | Badge | Meaning |
|-------|-------|---------|
| ✅ Complete | `✓-COMPLETE-success` | Tutorial finished |
| 🔵 Current | `●-CURRENT-blue` | Currently working on |
| ⚪ Todo | `○-TODO-lightgrey` | Not yet started |
